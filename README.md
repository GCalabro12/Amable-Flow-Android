# Amable Flow · app Android

App Android de [Amable Flow](https://gcalabro12.github.io/Flow/) (by Práctica Integral): muestra la web dentro de la app y añade lo que una web no puede hacer:

- ⏰ **Alarmas de verdad** para las acciones comprometidas: suenan aunque la app esté cerrada o el móvil bloqueado.
- 🗣️ La voz de los ejercicios (con la voz de Android).

Descarga la última versión: https://github.com/GCalabro12/Flow-Android/releases/latest/download/AmableFlow.apk
